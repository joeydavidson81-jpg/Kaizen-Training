## ⚡ Quick Start (3 Steps, 5 Minutes)

### For Developers:

```bash
# 1. Push to GitHub
cd speech-translator
git init && git add . && git commit -m "Initial commit"
git remote add origin https://github.com/YOUR_USERNAME/speech-translator.git
git push -u origin main

# 2. Deploy to Vercel
# Go to vercel.com/new → Select repo → Deploy

# 3. Share the Live URL with Users!
# That's it! 🎉
```

### For Users:
1. Click the link you received
2. Allow microphone access
3. Speak and get instant translations

## ✅ What This App Does

✨ **Users speak** into their browser microphone
✨ **App transcribes** their speech in real-time
✨ **App translates** to the target language
✨ **Shows translation** instantly on screen
✨ **Works on phone or computer**
✨ **Completely free** (no API keys needed)

**Supported Languages:** English ↔ Mandarin Chinese
